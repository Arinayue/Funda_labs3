Все команды выполнять из папки task6.

Сборка:
gcc main.c input.c transport.c -lm -o task06.exe

Создать bus.txt с двумя маршрутами BUS1 и одним маршрутом BUS2:
@'
0 0
BUS1;01.01.2025 08:00:00;01.01.2025 08:05:00;S
BUS1;01.01.2025 09:00:00;01.01.2025 09:05:00;E
BUS1;01.01.2025 10:00:00;01.01.2025 10:05:00;S
BUS1;01.01.2025 11:00:00;01.01.2025 11:05:00;E
BUS2;01.01.2025 08:00:00;01.01.2025 08:05:00;S
BUS2;01.01.2025 09:00:00;01.01.2025 09:05:00;E
'@ | Set-Content -Encoding ascii bus.txt

1. Максимум и минимум маршрутов
@'
1
2
0
'@ | .\task06.exe bus.txt

Ожидается: запрос 1 выбирает BUS1, запрос 2 — BUS2.

2. Ошибка формата с номером строки
Создать файл с неверным типом остановки X:
@'
0 0
BUS1;01.01.2025 08:00:00;01.01.2025 08:05:00;X
'@ | Set-Content -Encoding ascii bad_bus.txt
.\task06.exe bad_bus.txt
Ожидается сообщение о некорректном формате; ошибка находится в строке 2.

3. Ошибка: маршрут начинается, но не заканчивается
@'
0 0
BUS1;01.01.2025 08:00:00;01.01.2025 08:05:00;S
'@ | Set-Content -Encoding ascii open_route.txt
.\task06.exe open_route.txt
Ожидается сообщение о некорректном маршруте BUS1.

4. Ошибка: входной файл не найден
.\task06.exe nofile.txt
Ожидается сообщение об ошибке открытия файла.

5. Ошибка: не передан путь к файлу
.\task06.exe
Ожидается подсказка о необходимости указать один или несколько путей.

Удалить созданные файлы:
Remove-Item bus.txt, bad_bus.txt, open_route.txt
