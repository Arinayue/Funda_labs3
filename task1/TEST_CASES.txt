Все команды выполнять из папки task1.

Сборка и запуск:
gcc main.c func.c -o task01.exe
.\task01.exe

Программа запускает набор проверок автоматически. В выводе проверь:
- 56 при r=1: base 2, результат 111000;
- 56 при r=2: base 4, результат 320;
- -42 при r=3: base 8, результат -52;
- значения 0, 1, -1, LLONG_MAX и LLONG_MIN;
- для r=6 выводится ошибка "r must be in range 1..5";
- для нулевого указателя выводится "null pointer passed".

Код завершения 0 означает, что программа отработала.
