Все команды выполнять из папки task7.

Сборка:
gcc main.c io.c livers.c -lm -o task07.exe

Создать входной файл:
@'
Young;Bob;B;01.01.2000;M;60000
Old;Alex;A;01.01.1950;M;50000
'@ | Set-Content -Encoding ascii livers.txt

1. Проверка порядка и поиска
Список упорядочивается по дате рождения: сначала самый старший житель.
Вставить блок в PowerShell:
@'
1
*;*;*;*;M;*
0
'@ | .\task07.exe livers.txt

Ожидается, что Old будет выведен раньше Young.

2. Поиск без совпадений
@'
1
Nobody;*;*;*;*;*
0
'@ | .\task07.exe livers.txt
Ожидается: "Совпадений нет".

3. Ошибка формата во входном файле
@'
This line has no semicolons
'@ | Set-Content -Encoding ascii bad_livers.txt
.\task07.exe bad_livers.txt
Ожидается сообщение об ошибке формата с номером строки 1.

4. Ошибка фильтра: все поля заменены на *
@'
1
*;*;*;*;*;*
0
'@ | .\task07.exe livers.txt
Ожидается сообщение о неверном формате фильтра.

Удалить созданные файлы:
Remove-Item livers.txt, bad_livers.txt
